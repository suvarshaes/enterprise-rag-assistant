# Angular frontend

Install dependencies and start the development server:

```powershell
npm ci
npm start
```

The app is available at <http://localhost:4200> and calls the ASP.NET Core API at <http://localhost:5000>. Start the API and Python service first; see the [repository setup guide](../README.md).

Run the frontend tests with `npm test` and create a production build with `npm run build`.
